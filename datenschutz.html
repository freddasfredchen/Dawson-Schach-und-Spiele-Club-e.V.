Diese Website setzt keine Cookies, enthält keine Analyse- oder Trackingwerkzeuge und lädt keine Inhalte von Drittanbietern (keine externen Schriften, Karten oder Videos). Alle Dateien einschließlich des Logos werden vom selben Server ausgeliefert.

GitHub protokolliert die IP-Adressen der Besucher nach eigenen Angaben aus Sicherheitsgründen. Eine genaue Speicherdauer nennt GitHub nicht; Einzelheiten in der Datenschutzerklärung von GitHub. Wir selbst erhalten und speichern diese Zugriffsdaten nicht.
